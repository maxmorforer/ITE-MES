# Tutorial 4 - Part B: Git Collaboration

## Purpose of the Repository
The purpose of this repository is to demonstrate the use of Git and GitHub for version control and collaboration. It was created to practise creating branches, adding files, committing changes, submitting Pull Requests, reviewing changes, and merging branches.

## Steps Followed
1. Installed Git and created a GitHub account.
2. Created a local Git repository.
3. Created a public GitHub repository.
4. Added my classmate as a collaborator.
5. Created a new branch for the tutorial.
6. Added a sample file containing my name.
7. Committed the file with a descriptive commit message.
8. Pushed the new branch to GitHub.
9. Created a Pull Request and assigned my collaborator as the reviewer.
10. Received approval from my collaborator and merged the Pull Request into the main branch.
